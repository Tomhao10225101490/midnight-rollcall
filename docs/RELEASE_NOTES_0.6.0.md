# 末铃点名 0.6.0 · 校园材质与分章配乐开发预览

独立离线运行的单人桌面校园恐怖逃生游戏。仍为开发预览；高级商业音画品质和首次玩家20—30分钟时长尚未验收。

本次改进：
- 原创立体窗户、磨砂玻璃、暖气旁窗台，以及办公室档案柜的门缝、通风槽、合页、分类牌。
- 建筑表面按实际尺寸平铺原创抹灰和水磨石，分离颜色、凹凸与粗糙度贴图，改善长墙拉伸。
- 走廊四处灯具对应的局部动态阴影与漫射补光；保留可关闭环境遮蔽和画质设置。采用实时近似，不是路径追踪或完整全局光照。
- 五段随解谜阶段变化的原创配乐，以及带短暂延续的追逐动机；暂停保留乐句，重开清理旧音符和混响。修复追逐状态残留到新游戏首帧。
- 内置官方原版 Noto Sans SC 中文字体，离线显示菜单、字幕、黑板及试卷；启动等待字体就绪，缺失或损坏时给出可重试错误。字体按 SIL OFL 1.1 保留版权与许可，不归项目 MIT 许可。
- 修复快速关闭记录或谜题面板时，延迟鼠标解锁事件造成重复暂停的时序问题；真正 Esc、失焦、最小化仍暂停。

Mac 选 arm64（M 系列）或 x64（Intel）的 DMG/ZIP；Windows 选安装或便携 EXE；Linux 选 AppImage 或 tar.gz。桌面软件内置运行时，无需 Node 或联网。web.zip 为次要的独立静态构建。

应用未提供开发者签名与苹果公证。核实来源及 SHA256 后，按项目 [安装说明](https://github.com/Tomhao10225101490/midnight-rollcall/blob/main/docs/INSTALL.md)允许单个可信应用运行，不关闭全局系统保护。

发布验收：五个原生/静态构建job成功，九个包核对内部版本、入口、53个递归运行模块及字体许可；11项远端资产大小及SHA256与独立CI清单一致。实际下载的Mac arm64 ZIP应用完整断网键鼠通关，3次捕获后正常检查点续玩，HTTP请求和页面错误均为0；启动、输入、设置、快速记录开关及DMG只读挂载/安装入口检查通过。

Windows/Linux/macOS Intel仅对应系统CI构建与包内容检查通过，未实机试玩。浏览器版仅基础启动、菜单、暂停和实际ZIP检查，未整局试玩。自动声学检查不等于主观听感评审，20—30分钟首次玩家时长仍未实测。
