# 末铃点名 v0.3.0 · 探索与音画开发预览

这是可独立离线运行的桌面开发预览，仍非最终品质验收版。20—30分钟首次游玩体验尚未测定；目前的程序化美术与合成音乐不代表已达到用户要求的高级商业游戏品质。

相较0.2.0：
- 一班试卷与二班登记组合解开档案密码；办公室与纪律室两处线索组合恢复广播。新增值班日记，收集内容可随存档保留，旧版存档迁移。
- 五类任务设备替换占位方块；修复公告贴图覆盖，区分木材/墙面/金属，设备增加倒角；值班人新增连续面部、衣领、眼镜、手指与分节动作。
- 原创脚步、门轴门闩、校铃、广播提示；值班人脚步有距离衰减、方向声像和隔墙滤波。探索配乐加入缓起弦音、随进度变化的和声及留白。
- 笔记按记录切换并提供三级提示；暂停中可调整设置，新增视野角度及四档精细度，设置保存后生效。
- 修复贴近外墙的合法目标导致寻路停滞，以及铃声期间藏入被错误追溯目击的问题。
- 静态建筑实例化以减少重复绘制，动态门与出口保持独立。

桌面包内置运行时，不需要Node或浏览器。M系列Mac选arm64，Intel Mac选x64，Windows选setup或portable，Linux可选AppImage或tar.gz。网页ZIP是辅助构建，没有在线试玩地址。

没有Apple开发者签名/公证与Windows代码签名，系统可能提示来源未知。请先核实项目来源及SHA256，再使用官方单应用确认方式；安装说明见仓库docs/INSTALL.md，不要求关闭全局安全保护。

Windows、Linux、Intel Mac的构建与实体设备试玩是不同验证范围，未实机的平台不会标成已试玩。详细测试记录见VERIFY.md，文件大小及SHA256随Release附带。

## 本次实际验证
- 修复版源码及本机打包的macOS Apple Silicon应用均完成实际键盘路线通关，包含3次被捕和正常检查点续玩，没有瞬移、无敌或道具注入。不是首次玩家时长测量。
- 15项逻辑测试与TypeScript检查通过；视野、精细度、设置重载保留、暂停设置返回、笔记回看经过界面操作测试。
- macOS arm64/x64、Windows x64、Linux x64及Web的CI构建均成功。Windows、Linux、Intel Mac未实机试玩；Web只做过基础浏览器运行验证，不宣称整局试玩。
- 全部9个包已逐个检查内部资源/入口/版本，并与远端Release大小及SHA256匹配；诊断相机近景仅用于美术检查，不冒充正常玩家截图。
