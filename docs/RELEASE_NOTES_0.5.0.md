# 末铃点名 0.5.0 · 搜查与校园叙事开发预览

可独立离线运行的单人桌面校园恐怖逃生游戏。仍是开发预览，高级商业音画品质与首次玩家20—30分钟体验尚未验收。

本次改进：
- 巡查者抵达最后看到或听到的位置后，会停步观察并搜查附近可达区域。抵达时至少保留六秒有限搜查，未目击的隐藏位置不会被用于路线规划。
- 随身记录新增教学楼疏散示意图，标出房间用途、门口与玩家当前区域；记录和逐级提示仍可回看。
- 开场身份、空间触发的原创校园叙事、途中记录；原创轻敲、荧光灯、暖气片、23:58校钟。
- 原创人物连续面部曲面、眼睑与虹膜、外套织纹；保留可关闭接触阴影和画质档位。
- 档案柜/广播台数字键盘、配电开关与错误反馈，支持Enter、Space、Esc和小窗口滚动。
- 可跳过被捕演出与清晰追逐提示；原生窗口焦点通知修复Mac最小化后仍推进演出的问题。
- 本地中文广播时平滑压低音乐，播报结束后恢复；修复首次语音列表尚未就绪和静音残留的问题。无离线中文语音时保留广播提示音与完整字幕。

验证范围以本次实际发布报告为准。源码已通过21项逻辑测试，完整键盘逃生与正常引诱后入柜观察搜索测试；没有瞬移、物品注入或无敌。音频图与本地播报状态验证不代表主观听感评审。Windows/Linux/macOS Intel仅对应系统CI构建与包内容检查，不代表实机试玩。

Mac选arm64（M系列）或x64（Intel）的DMG/ZIP；Windows选安装EXE或便携EXE；Linux选AppImage或tar.gz。web.zip为次要的独立静态构建。桌面版内置运行时，无需Node或联网。

应用未提供开发者签名与苹果公证。核实来源与SHA256后，按[Apple官方说明](https://support.apple.com/zh-cn/102445)允许单个可信应用运行；Windows参考[Microsoft SmartScreen说明](https://support.microsoft.com/windows/what-is-smartscreen-5a0a1631-8f9a-4cd7-a3a6-c85bca56d5b9)。不要关闭全局系统保护。

发布验收：五个原生/静态构建任务通过，九个包均核对内部入口、版本与48个递归运行模块；全部远端资产大小及SHA256匹配。实际下载的Mac arm64 ZIP应用已通过完整网络禁用键盘逃生（3次捕获后正常检查点继续，0个HTTP请求、0个页面错误），菜单/鼠标锁定/设置通过；DMG只读挂载及安装入口通过。
