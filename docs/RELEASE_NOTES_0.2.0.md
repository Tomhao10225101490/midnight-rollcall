# 末铃点名 v0.2.0 · 可玩开发预览

这是可独立运行的离线桌面游戏预览，**不是最终品质验收版**。高品质建模/音乐及20—30分钟首次游玩体验仍在完善，不能把自动熟练路线时长当作设计时长。

包含原创校园地图、值班人追捕/搜索、碰撞遮挡、门与开门声、奔跑警戒、躲藏及被目击搜查、试卷/档案/广播/配电任务链、铃声逃生窗口、胜败与检查点续玩、设置和存档、分层合成配乐及本机离线语音字幕。

## 验证范围
- macOS Apple Silicon：本机源码运行和0.2.0打包应用均通过完整键盘通关，包含1次被捕和正常检查点续玩，没有瞬移、无敌或道具注入。不是一命通关或独立玩家主观评价。
- CI下载的arm64应用另行检查启动、菜单、输入、暂停和设置。
- Windows x64、Linux x64、Intel macOS：对应系统CI构建，未在实体设备试玩。
- Web：本机Chrome启动和暂停测试，未整局通关。
- 10项逻辑测试、类型检查、重开资源计数、音频信号/静音/暂停测试通过；不代表商业级音画品质认证。

## 下载选择
M系列Mac选择mac-arm64；Intel Mac选择mac-x64。Windows选择setup安装版或portable便携版。Linux优先选择tar.gz，或使用AppImage。Web ZIP是静态构建，桌面用户无需下载它。所有桌面包内置运行时，不需安装Node。

## 未签名与安装
无Apple Developer签名、公证或Windows签名证书，可能触发系统提示。仅在核实项目来源和SHA256后使用系统的单应用确认方式，勿关闭全局安全保护、勿运行来源不明的绕过脚本。具体步骤和官方来源见仓库docs/INSTALL.md。

游戏完全虚构，无血腥。建议低音量；无镜头晃动或刻意闪烁。操作：WASD移动、Shift奔跑、Ctrl潜行、E互动、H储物柜躲藏、J记录、Esc暂停。
