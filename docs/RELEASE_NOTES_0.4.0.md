# 末铃点名 0.4.0 · 柜内窥视与校园家具开发预览

这是可离线运行的单人桌面恐怖逃生游戏开发预览，仍未达到最终音画与时长验收标准。

本次改进：
- 储物柜具有实体碰撞，柜前按 H 藏入，通过真实百叶通风缝观察；视角受限，退出恢复进入位置。被目击藏入仍会遭搜查。
- 原创圆角课桌、开放书斗、钢架课椅与双门储物柜；两间教室使用不同粉笔黑板内容，清理悬空占位标牌。
- 可关闭的接触阴影，全部渲染依赖随安装包离线提供；新增方向键观察。
- 原创阻尼弦波导音色，继续使用自适应配乐与本机合成音效。
- 安装包检查递归验证全部运行模块，避免遗漏间接渲染依赖。

验证范围：Mac Apple Silicon 开发源码已通过完整键盘路线（3次捕获后正常检查点续玩，无瞬移或物品注入）。0.4开发打包应用已验证启动、输入、设置、音频图和柜内操作。正式0.4.0本机打包应用也已通过完整键盘路线（3次捕获后正常续玩）；公开下载包的检查以发布验收报告为准。Windows/Linux/macOS Intel仅对应系统CI构建及包内容检查，不代表实机试玩。

18项逻辑测试包含导航、门、碰撞、敌人视听、躲藏搜查、存档、设置、谜题和声音波形。设计目标20—30分钟，不是已实测首次游玩时长。模型、美术和配乐仍在完善，未宣称高级商业游戏品质或完成主观听感验收。

## 下载选择
- Apple Silicon Mac：mac-arm64.dmg 或 mac-arm64.zip。
- Intel Mac：mac-x64.dmg 或 mac-x64.zip。
- Windows 64位：win-x64-setup.exe；免安装可选 win-x64-portable.exe。
- Linux 64位：AppImage，或 linux-x64.tar.gz 解压运行。
- web.zip为独立静态网页包，属于次要交付；桌面版本无需Node、浏览器或联网。

本项目无代码签名和苹果公证证书，系统可能提示开发者未经验证。确认来源和SHA256后，按[Apple官方说明](https://support.apple.com/zh-cn/102445)允许单个可信应用运行；Windows按[Microsoft SmartScreen说明](https://support.microsoft.com/windows/what-is-smartscreen-5a0a1631-8f9a-4cd7-a3a6-c85bca56d5b9)评估提示。不要关闭全局系统保护。校验文件随本次发布附带。
