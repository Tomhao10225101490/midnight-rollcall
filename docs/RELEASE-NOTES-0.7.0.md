# 末铃点名 0.7.0 开发预览

本版本候选新增门扇近景细节与真实开门碰撞、原创结局曲《末铃之后》和重新制作的出口庭院。安装后离线运行，不需要Node、账号或网络服务。

- 木框、压条、把手、锁孔、踢脚板和合页；打开门扇仍遮挡视线和行走，玩家与追捕者可绕行，开关门拒绝夹住角色。
- 音频上下文恢复/暂停串行处理，修复快速从线索返回再暂停时可能遗留运行状态的问题。
- 逃生后播放33秒本地原创编排音乐，总音量与播报压低生效；失焦暂停、恢复续播，重开停止并归零。
- 出口加入铺石接缝、排水沟、长椅、树木枝叶、边界栏杆、打开外门和雾中建筑；晨光阴影只在结局开启，重开恢复夜间。

这是持续打磨的开发预览，不代表已达到顶级商业美术或音乐品质。20—30分钟是首次玩家设计目标，尚无独立首次玩家实测；熟悉答案的自动键鼠通关不能替代该验收。

开发包Mac实测：正常键鼠断网通关，3次捕获后正常检查点续玩，HTTP/页面错误均0；结局音乐及暂停恢复通过；8次重开资源数量稳定。31项逻辑测试通过，音频修复后的桌面整局复验进行中。

发布前状态：原生构建曾两次在GitHub服务启动阶段失败，尚未产生各平台CI包。当前音频修复候选需重新完成桌面整局与原生构建、安装包校验、实际下载Mac应用复验和公开Release。公开可下载版本仍为0.6.0。
