# Scanned school furniture

These models are official Poly Haven CC0 1.0 downloads. They are not paid assets.

- School Desk 01 (2K glTF): https://polyhaven.com/a/SchoolDesk_01
- School Chair 01 (2K glTF): https://polyhaven.com/a/SchoolChair_01

Files were copied unaltered from the Poly Haven 2K glTF packages (mesh `.bin`, `.gltf`, and JPEG `diff` / `nor_gl` / `arm` textures). License text is in `LICENSE-CC0-POLYHAVEN.txt` and each model's `LICENSE-CC0.txt`. SHA256 hashes are in `manifest.json` and verified at build time.

If a model fails to load, the game falls back to the original procedural desk and chair in `src/furniture.ts`.
